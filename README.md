# 前端面试题整理

一份持续整理的前端面试资料，涵盖 CSS、TypeScript、Vue、React、网络基础、业务场景题以及 AI 辅助开发等主题。

## 内容导航

| 主题 | 内容 |
| --- | --- |
| [AI 辅助开发](./ai.md) | AI 开发工具、Agent、MCP 与特殊内容渲染 |
| [CSS](./css.md) | 选择器、布局、响应式、动画与常见样式实现 |
| [React](./react.md) | Hooks、路由、渲染流程与性能优化 |
| [TypeScript](./ts.md) | TypeScript 类型与基础用法 |
| [Vue](./vue.md) | Vue 2/3、Composition API、响应式与虚拟 DOM |
| [场景题](./场景题.md) | 权限、工程规范、团队协作、大数据加载与文件上传 |
| [网络资源](./网络资源.md) | WebSocket、SSE、跨域、存储、CDN 与缓存 |

## 使用方式

- 按主题阅读对应文档。
- 面试前用问题标题快速自测，再展开答案查漏补缺。
- 内容会持续补充和修订，欢迎提交 Issue 或 Pull Request。
